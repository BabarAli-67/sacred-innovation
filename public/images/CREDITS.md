Placeholder stock photography from [Unsplash](https://unsplash.com), downloaded
into the repo so the site has no runtime dependency on an external host and
nothing can 404. The Unsplash licence allows commercial use without
attribution; this file records provenance so each image can be traced or
swapped.

Every one was downloaded, viewed and matched to its section by subject before
being committed — none were chosen from a filename.

**These are placeholders.** Replace them with Sacred Innovations' own project
photography before launch; the brand foundation (section 09) asks for
